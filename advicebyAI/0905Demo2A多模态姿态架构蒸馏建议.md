# Demo2A 多模态姿态架构蒸馏建议

> 日期：2026-09-05
> 类型：architectural advice / distilled engineering lessons
> 证据边界：本文件是基于仓库 research/paper/repo 与 EgoGlove 当前代码、V8 文档的项目适配建议，不是第三方原始事实，也不表示相关实现已经接入。

## 仓库内证据

- Demo1 当前真实资产证明 transport、replay、可视化和 7-IMU+3-HKVT 的现场链路；它不证明 Demo2 多模态 pose、global wrist 6DoF 或 calibration gate 已通过。
- V8 已将 Observation、Episode、Coordinate Profile、Provenance 与 Hand Token 分层；Hand Token v2 继续是 Motion Transport Layer。
- `relay/semantic_fixtures.py` 当前 executable semantic profile 使用 `+Z forward`；V7 旧 prose 中存在 `-Z forward`，因此 Demo2 spec 显式以 executable profile 冻结 `+Z forward` 并记录冲突。

## 项目适配判断

1. 从 Demo2A 开始冻结 10+1-capable 的 logical namespace、frame naming、clock mapping、calibration envelope 和 Canonical Hand State；Demo2B 只增加 secondary IMUs/factors，不重写基础 Episode/Data 层。
2. 把 `device_timestamp`、`host_rx_timestamp`、`sequence`、`sensor_id`、`clock_domain`、`quality` 留在 Raw Observation/Observation 层；不要把多模态时间字段塞回 Hand Token v2。
3. 对所有 `T_B^S`、`T_I^C` 强制 calibration provenance。柔性 textile/FPC 上的传感器若不能保持稳定 rigid island，就不能静默套用固定外参。
4. 6-axis IMU 只作为 roll/pitch 和相对 segment orientation 的强约束；yaw 不能写成长期 absolute heading。wrist camera 只在其 measurement responsibility 范围内进入 vision factor。
5. flex 只产生 bend constraint，FlexiTac 只产生 contact/pressure/centroid/quality observation；二者都不能被写成关节角真值。
6. Canonical Human Hand State 是 Sensors/Observations 与下游 adapters 之间的稳定层；MANO、OpenXR、ROS、BVH、URDF/MJCF/USD、Dex-Retargeting/AnyTeleop、RLDS/LeRobot 都从该层投影出去。
7. Demo2A 可用 confidence-gated complementary/Slerp baseline，但 factor contract 必须允许未来 fixed-lag/sliding-window nonlinear solver 无破坏升级。

## 未验证假设与开放边界

- 本地没有足够的一手证据证明 Kalibr、GTSAM、VINS-Mono、AnyHand、hand-tracking-fusion-system 或 xio Fusion 已被 EgoGlove 采用；本 milestone 不把它们写成既有依赖。
- 具体 finger IMU segment assignment、global reference source、GT fixture 和 accuracy thresholds 仍需单独授权/验证。
- FSGlove、HumanEgo、MANO、FlexiTac gallery 和 robot assets 的许可证不能由“开源/论文可见”推断为可商用。

## 建议动作与明确不做

本建议只支持审阅 `Demo2A Multimodal Pose Architecture Spec v0.1`。本轮不实施 PCB/FPC、10+1 driver、完整 MANO/GTSAM/Ceres/VINS solver、CV 模型、LeRobot/RLDS exporter 或新的下游 adapter；不修改 Hand Token v2。
